# probefont

Probe CSV/TSV font tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/probefont/

## Install / run

```bash
git clone https://github.com/theworker02/probefont.git
cd probefont
node src/cli.js
node --test
```
